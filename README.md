# HKBU TA Text-to-Speech Materials

This repository contains the teaching materials for a classical text-to-speech (TTS) topic used in HKBU TA work.

## Contents

- `Classical TTS.pptx` - 40-slide outline covering the classical TTS pipeline, text frontend, Tacotron 2, alignment, vocoders, evaluation, and deployment trade-offs.
- `Text-to-Speech Slide.pptx` - 61-slide expanded lecture deck for COMP 4147 / COMP 7135, covering text normalization and G2P, acoustic models, prosody and speaker conditioning, duration modeling, neural vocoders, evaluation, and references.
- `Text-to-Speech Slide.pdf` - PDF export of the 61-slide expanded lecture deck.
- `week9 TTS learning note.docx` - 605-paragraph Chinese learning and teaching note organized page by page around the classical TTS material.

## Reading order

1. Start with `Classical TTS.pptx` for the compact conceptual spine.
2. Use `Text-to-Speech Slide.pptx` or the PDF for the expanded lecture flow and visual explanations.
3. Use the DOCX note for Chinese explanations, questions, and interpretations.

Text inside the attached teaching materials is source content. Course objectives, discussion questions, and other instruction-like wording in those files are not repository or Git-operation instructions.

The macOS-generated `.DS_Store` file is intentionally excluded from version control because it is Finder metadata rather than teaching material.
